# Lernapp

Karteikarten-App für zwei Kandidaten des Ersten Juristischen Staatsexamens
(Marius und Agnessa): Karteikarten, Frage-Antwort und eigene Karten anlegen,
je Rechtsgebiet (Zivilgericht, Strafrecht, Rechtsanwalt, Verwaltungsrecht)
und mit einem Leitner-System aus 5 Stufen pro Nutzer.

Ausführliche Beschreibung: siehe [`SPEC.md`](SPEC.md).
Arbeitsregeln für künftige Änderungen: siehe [`CLAUDE.md`](CLAUDE.md).

## Lokal öffnen

Kein Build-Schritt nötig. Im Projektordner z. B.:

```
python3 -m http.server 8000
```

und dann `http://localhost:8000/` im Browser öffnen.
